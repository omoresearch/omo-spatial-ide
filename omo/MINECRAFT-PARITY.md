## Verdict

- 60 entries; 202/202 anchors verified across 68 files; problems: 0.
- Real integrations: 44. Standalone at the baseline snapshot: present 3, partial 10, contract-only 8, missing 21, n/a 2.
- The portable backbone is the bridge's tmux model (RT-01..RT-25), not the Java/Lua plumbing. At the pinned baseline, the standalone has one non-persistent Theia terminal on a monitor; `runtime-protocol.ts` defines the interface but does not implement it. Later implementation is tracked separately in `INTEGRATION.md` and `RUNTIME.md`.
- Contract gaps (not in runtime-protocol.ts): workspace list/rename/delete, setWorkspaceProfile, keepAwake, Claude session id, scroll/find/clear, copy/paste/OSC52/open-link, bell, station-level tab steer, limits, board.
- Not in the Minecraft product at all (do not report as gaps): self-update, voice, code editor/diffs. Agent bodies over LAN is an experiment, not an IDE integration.

1. **AT-01 Shell survives backend restart and tmux loss** (RT-01, RT-10) - Start `sleep 600` and `cd $TMPDIR/omo-at`, restart Theia backend -> same PID alive. Then kill only the standalone TEST tmux socket and reopen the workspace -> same tab names/order, pwd $TMPDIR/omo-at, nothing re-run, detail says restored N. _Surface: openWorkspace, newTab, attach, poll._
2. **AT-02 Honest agent availability** (RT-03, RT-04, SET-01) - PATH with stub hermes only: status() -> hermes available, claude/codex available=false with installHint; new Claude tab shows the hint; no crash. _Surface: status, newTab._

4. **AT-04 Typing, Ctrl keys and safe paste** (RT-18, RT-27) - Monitor focused: Ctrl+R reaches bash; paste 'echo a\necho b' runs nothing until Enter; 300 KiB paste refused; Esc returns to walking. _Surface: input._
5. **AT-05 Hermes profile per workspace** (RT-07) - openWorkspace(profile=P1) -> stub hermes argv carries P1; setWorkspaceProfile(P2) -> next Hermes tab carries P2; running tab untouched. No model calls. _Surface: openWorkspace, newTab (+ new setWorkspaceProfile)._
6. **AT-06 Claude Code resume after restore** (RT-05) - Stub claude logs argv: --session-id U on first launch; after kill-server + reopen, --resume U. _Surface: newTab, openWorkspace (+ session field)._
7. **AT-07 Tab lifecycle with confirmation** (RT-09, RT-08) - closeTab(confirmedClose=false) on busy tab refused; true closes; reviveTab on exited tab -> running; Resume Hermes refused while `sleep` runs. _Surface: closeTab, reviveTab, renameTab._
8. **AT-08 Local-only, no credentials in the browser** (RT-22, MP-01) - Backend bound to 127.0.0.1; frontend traffic contains no token; foreign Host header refused. _Surface: all._
9. **AT-09 Desk keeps its workspace across reload** (WLD-02, RT-28) - Desk A -> workspace W with 2 tabs; reload IDE; desk A reattaches W (same id, same tabs); rebind desk A to W2 via picker persists. _Surface: openWorkspace(stationId)._
10. **AT-10 Auto-sleep safety** (RT-12, RT-13) - Stub hermes idle and unwatched with short OMO_SLEEP_AFTER -> sleeping after clean /exit; attach wakes same conversation; watched/drafted/working/keep-awake tabs never sleep. _Surface: poll state 'sleeping'._
11. **AT-11 Two surfaces, one tab** (RT-14, WLD-05) - Desk monitor 80x22 and wall 120x40 on one tab both get frames; selecting another tab moves both. _Surface: attach x2._
12. **AT-12 Scrollback, find, copy** (RT-16, RT-17) - seq 1 5000: wheel scrolls history; find '1234' brings it into view; double-click copy puts the word on navigator.clipboard; clear empties history. _Surface: new scroll/find/copy ops._
13. **AT-13 Visible agent state** (RT-25, RT-26, RT-24) - During `sleep 3` desk light gold and busy=true; after, green; after kill-server, red. Board view lists names/states with no ids/tokens. _Surface: poll, listWorkspaces._
14. **AT-14 Web wall** (WEB-01, WEB-02) - Bind https://example.com to a wall: renders on texture, clicks reach page, binding survives reload; javascript:/file: refused. _Surface: frontend only._
15. **AT-15 Preset rooms are shareable** (WLD-03, WLD-04) - Preset desk {hermes, tabs [Hermes, Shell]} builds those tabs on a clean host; committed room file has no workspace ids, tokens or home paths. _Surface: openWorkspace._
