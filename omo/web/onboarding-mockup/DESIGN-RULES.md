# Omo Space IDE landing mock-up: design rules

Sources studied (2026-11-20):
- resend.com (live, full-page headless capture: references/resend-home.png, resend-part*.png)
- cursor.so, March and June 2023 launch pages (Wayback captures: references/cursor-2023-*.png)
- Real Omo Spatial IDE screens (~/dev/omo-w3-look/omo/design-shots/*.png) for product truth:
  desks, in-world screens, the web wall, rooms with codes, voice, agents, mint active state.

## Rules

1. Black is the canvas. Use true black (#000) for the page. Do not use a coloured background. Depth comes from
   light, not from grey boxes. (Resend)
2. One editorial serif for the big statements, one quiet sans for everything else. Large serif headlines,
   set tight (line-height about 1.0), with grey 17-18px body copy under them. (Resend)
3. Images dissolve into the dark. No image has a hard edge or a frame. Each generated image has black
   edges, and the page adds a soft mask so the art comes out of the dark. (Resend hero, Cursor editor glow)
4. One accent colour, used for meaning. Mint (#7CF2D0, taken from the real product's active state) is
   for the main action and the "live" signals. Everything else is white or grey. (Cursor's single green or blue CTA)
5. Short promises, said with confidence. Each section gives one idea in a short line and one plain
   sentence. No stacks of feature bullets. ("Build Software. Fast.")
6. Show the product moment, not a diagram. Each section shows the thing happening: the room still lit,
   voices near each other, the agent wired to every screen. (Cursor's prompt box in the editor)
7. Spark comes from small, precise light. Thin gradient hairlines, one soft glow behind the hero, a
   pulsing dot for "live". Do not use rainbow gradients or glass on everything. (Resend badge border, Cursor halo)
8. Plenty of space, a strict grid. Large vertical gaps between sections. A centred 1120px column. Features
   alternate left and right so the eye moves. (Both)
9. A real action, not "Learn more". The CTA names the platform: "Open in browser", "Download for Mac".
   (Cursor's "Download for Linux")
10. Quiet chrome. Small grey nav, thin borders (#1c1c1c), pill buttons that are dark except for the one main
    action. (Resend)
